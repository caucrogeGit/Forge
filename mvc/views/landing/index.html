Framework web applicatif Python.

Forge génère un MVC CRUD explicite à partir d'un modèle JSON visible.

Forge s'adresse aux projets web qui ont besoin d'un vrai cadre applicatif, mais pas du poids complet d'un grand framework.

Deux parcours séparés : utiliser Forge pour créer une application, ou travailler sur le framework lui-même.

Créer une application avec Forge

Parcours utilisateur du framework

Pour installer la commande Forge, créer un projet et lancer le serveur de développement. 

# Dernière bêta
$ pip install --pre forge-mvc

# Version fixée
$ pip install forge-mvc==1.0.0b10

$ forge new mon-app
$ cd mon-app
$ forge doctor
$ python app.py

Version publique : 1.0.0-beta.10 — Version PyPI : 1.0.0b10
Forge est en bêta — --pre est requis avec pip ou pipx.

Contribuer au framework Forge

Parcours développement du core

Pour cloner le dépôt, installer l'environnement de développement et lancer les validations. 

$ git clone https://github.com/caucrogeGit/Forge.git

Guide développement
Pour la production, le déploiement est traité séparément : Nginx, systemd, variables d'environnement, HTTPS et contrôles avec forge deploy:check. Voir le guide de déploiement. Sur Windows, la voie recommandée est WSL2. Guide Windows (WSL2). Forge repose sur Python 3.12+, MariaDB, Jinja2 pour le rendu serveur, HTMX pour l'interactivité progressive, Alpine.js en option légère, et Tailwind pour les utilities CSS.

Starters progressifs.

Les starters Forge sont des points de départ progressifs. Ils servent à découvrir, tester et valider le framework, sans imposer une application métier unique. Ils ne remplacent pas le core.

5 modules officiels opt-in, conservés hors du core : forge-mvc-rbac, forge-mvc-workflow, forge-mvc-stats, forge-mvc-mfa, forge-mvc-media.

Questions fréquentes.

Forge remplace-t-il Django ?

Non. Forge ne cherche pas à remplacer Django. Django est un framework complet, mature et très riche. Forge vise une approche plus explicite et plus légère, adaptée aux projets où le développeur souhaite garder la main sur le SQL, les générateurs et la structure de l'application.

Forge utilise-t-il un ORM ?

Non. Forge garde le SQL visible. Les requêtes sont écrites et lisibles dans les modèles générés. Il n'y a pas d'ORM opaque imposé par défaut. Les migrations SQL sont des fichiers auditable.

Forge est-il stable ?

Forge est en bêta. La version actuelle est 1.0.0-beta.10. Plus de 12 000 tests — unitaires, documentaires, E2E, sécurité et MariaDB opt-in. L'API publique peut encore évoluer avant la version 1.0.0 stable.

Forge est-il adapté aux petites et moyennes applications ?

Oui. Forge est conçu pour les applications web MVC petites à moyennes : back-offices, outils de gestion interne, sites publics avec administration, prototypes et projets pédagogiques. Il n'est pas conçu pour les plateformes SaaS multi-tenant ou les architectures microservices complexes.

Forge peut-il servir pour enseigner le MVC ?

Oui, c'est l'un des cas d'usage explicites de Forge. La structure MVC est visible et explicite, le SQL est lisible, les générateurs produisent du code compréhensible, et la documentation est conçue pour accompagner l'apprentissage.

Quelle est la différence entre 1.0.0-beta.10 et 1.0.0b10 ?

Ce sont deux notations pour la même version. 1.0.0b10 est la notation PEP 440 utilisée par PyPI et pip. 1.0.0-beta.10 est la notation SemVer utilisée dans la documentation et les tags Git.

Où se place Forge ?

Forge se place entre Flask et Django.

Ce que Forge est
  • +Plus structurant que Flask
  • +Moins massif que Django
  • +Moins API-first que FastAPI
  • +Plus explicite qu'un framework magique
  • +SQL visible par défaut
  • +Génération contrôlée et réversible
Ce que Forge n'est pas
  • —Pas un clone de Django, Symfony ou Laravel
  • —Pas un ORM complet imposé
  • —Pas une SPA React/Vue intégrée au core
  • —Pas une boîte noire qui cache le SQL
  • —Pas une plateforme SaaS multi-tenant
  • —Pas encore stable (bêta)

Forge s'adresse aux projets web qui ont besoin d'un vrai cadre applicatif, mais pas du poids complet d'un grand framework.
