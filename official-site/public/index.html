Typage strict de bout en bout

Du cœur aux 12 modules opt-in, tout Forge passe pyright en mode strict et expose ses types via py.typed (PEP 561). La vérification est lancée en CI. Le code de votre application bénéficie de l'autocomplétion et de la vérification de types fournies par Forge, sans configuration (ADR-036).

Projets stricts par défaut

forge new génère un projet qui démarre directement en typeCheckingMode strict. Le code généré est propre en mode strict, et VS Code vérifie les types et auto-importe les classes du cœur dès le premier fichier écrit.

Accesseurs de requête précis

request.form(), query(), route() et header() exposent des surcharges typées : avec un default texte, le retour est une chaîne, jamais None. Le code idiomatique d'un débutant comme int(request.route("id", default="0")) est sûr en mode strict, sans garde manuelle.

Validation précoce des arguments

Response, l'enregistrement des routes et html() / render() valident leurs arguments critiques dès la construction : un statut HTTP correct, un handler réellement appelable. Les erreurs sont détectées tôt et clairement, plutôt que plus loin à l'exécution.

Générer sans masquer.

Forge automatise les répétitions, mais les fichiers restent visibles, auditables et modifiables.

Chaîne de génération

1. Tout part d'un fichier JSON d'entité canonique, source unique du modèle.

2. La commande forge entity:validate vérifie le contrat avant toute génération.

3. Le SQL et les migrations demeurent visibles et lisibles.

4. Le modèle *_base.py est régénéré à chaque exécution.

5. Le modèle manuel, lui, est toujours préservé.

6. Le contrôleur, le formulaire et les vues CRUD sont ensuite échafaudés.

7. Il en résulte une application MVC claire et maintenable.

$ cd mon-app
$ forge make:entity Contact
$ forge make:crud Contact --dry-run

Positionnement

Ce que Forge est
  • +Plus structurant que Flask
  • +Moins massif que Django
  • +Moins API-first que FastAPI
  • +Plus explicite qu'un framework magique
  • +SQL visible par défaut
  • +Génération contrôlée et réversible
Ce que Forge n'est pas
  • -Pas un clone de Django, Symfony ou Laravel
  • -Pas un ORM complet imposé
  • -Pas une SPA React/Vue intégrée au core
  • -Pas une boîte noire qui cache le SQL
  • -Pas une plateforme SaaS multi-tenant
  • -Pas encore stable (bêta)
