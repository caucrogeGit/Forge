# Avancé 1 — Activer un opt-in

Objectif : ajouter une brique optionnelle (authentification, back-office, etc.).

Forge garde un noyau minimal ; les fonctionnalités spécialisées sont des opt-ins
installés à la demande :

```bash
forge opt-in:install rbac
forge opt-in:enable rbac
```

Chaque opt-in a son propre parcours sur forgemvc.com (voir aussi les cartes
« Pour aller plus loin » de la page d'accueil de votre projet).

## Pour approfondir

Le contrat d'installation des opt-ins :
https://forgemvc.com/docs/forge/install/opt-ins/
