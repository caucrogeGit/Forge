# Intermédiaire 1 — Une page publique

Objectif : ajouter une page accessible sans authentification.

```bash
forge make:public-page
```

Forge crée le contrôleur, la vue et la route de la page.
Adaptez le contenu de la vue, relancez l'application, puis visitez la page.

## Pour approfondir

Les pages publiques :
https://forgemvc.com/docs/forge/reference/pages-publiques/
