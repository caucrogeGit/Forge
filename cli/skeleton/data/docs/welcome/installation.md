# Bienvenue dans votre projet Forge

Votre projet vient d'être créé.
Ce parcours vous guide pour vos premiers pas, directement dans cette application.

Chaque étape utilise les commandes `forge` de votre projet.
Pour approfondir un sujet, suivez les liens vers la documentation de Forge.

## Mettre en route

Vérifiez le projet, créez la base, puis lancez l'application :

```bash
forge doctor
forge db:init
python app.py
```

Ouvrez la page d'accueil : elle confirme que votre projet tourne et indique le
contrôleur et la route qui la servent.
