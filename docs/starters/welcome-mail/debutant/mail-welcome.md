# Bonjour Forge Mail

Premier contact avec l'opt-in `forge-mvc-mail`. Un formulaire saisit un destinataire et un message ; le contrôleur construit un `MailMessage` et l'envoie via `Mailer` sur un `ConsoleTransport` (l'email s'affiche dans la console, aucun serveur SMTP requis).

Palier suivant : [Composer un message](mail-message.md).
