Cette page rappelle les paramètres publics utiles du dépôt GitHub Forge.

---

## Champ Website

Dans GitHub :

```text
Repository → About → Edit repository details → Website
```

Renseigner :

```text
https://forgemvc.com/docs/forge/
```

Ce lien permet aux visiteurs d'accéder directement à la landing page et à la documentation Forge depuis la page du dépôt.

## Visibilité du site dans le README

Le fichier `README.md` contient une section **Liens rapides** en tête de document.
Elle renvoie vers la landing page, les tests terrain, l'état des parcours et le formulaire de retour testeur.

Cette section est le point d'entrée visible pour tout contributeur ou visiteur arrivant directement sur le dépôt GitHub.
