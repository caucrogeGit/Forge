# Bilan : niveau intermédiaire (Stats)

Récapitulatif du **niveau intermédiaire** de la progression *Welcome Stats*.
Ce niveau couvre l'**enregistrement** : voir le SQL, tracker, valider.

## Ce que vous avez validé

| Palier | Compétence acquise |
|--------|--------------------|
| 1 : [Le SQL d'insertion](stats-track-sql.md) | Voir l'`INSERT` et ses valeurs (`get_track_event_sql`). |
| 2 : [Enregistrer un événement](stats-track.md) | Tracker via un exécuteur injectable (`track_event`). |
| 3 : [Valider un événement](stats-validate.md) | Refuser avant d'écrire (`validate_event`). |

Vous savez enregistrer des événements valides, à SQL visible et code testable.

## Et ensuite

Place au niveau **avancé** : **consulter** : le SQL de lecture, lister, normaliser.

[Niveau avancé : Le SQL de consultation](../avance/stats-admin-sql.md)
