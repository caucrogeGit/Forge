# Bilan : niveau débutant (Fixtures)

Récapitulatif du **niveau débutant** de la progression *Fixtures*.

## Ce que vous avez validé

| Palier | Compétence acquise |
|--------|--------------------|
| 1 : [Bonjour les fixtures](fixtures-welcome.md) | Comprendre ce qu'est une fixture et la frontière avec la migration de seed. |
| 2 : [Charger une première fixture](fixtures-load.md) | Écrire un `.sql` dans `mvc/fixtures/`, afficher le SQL, charger avec `--run`. |

Vous savez peupler une base de développement avec des données rejouables, à SQL visible.
