# Bilan : niveau avancé

Vous savez maintenant :

- supprimer une ligne via une confirmation contrôlée, jamais en GET ;
- surcharger n'importe quel template du back-office depuis votre projet ;
- exiger une permission RBAC en option, sans verrouillage par surprise ;
- vérifier la cohérence avec `forge admin:doctor`.

Vous avez parcouru tout le cycle d'administration d'une entité.
