# Bilan — niveau débutant

Vous savez maintenant :

- ouvrir le back-office sous `/admin`, protégé par l'authentification ;
- déclarer une entité administrable avec `AdminResource` ;
- consulter une liste paginée, lue par une requête contrainte.

Le back-office affiche désormais vos articles.
Le niveau suivant ouvre la consultation détaillée et l'écriture.
