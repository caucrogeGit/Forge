Servir un fichier

Indiquez le chemin relatif d'un fichier stocké (celui renvoyé par le palier « Stocker un document », p. ex. documents/mon-fichier-abcd.pdf).

Un chemin qui tente de sortir de la racine d'upload (p. ex. ../secret) est refusé : serve_media_file protège contre la traversée de répertoire et répond 404.
