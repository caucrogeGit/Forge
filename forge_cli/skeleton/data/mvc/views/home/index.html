Projet Forge

Votre projet Forge tourne

Cette page est servie par mvc/controllers/home_controller.py via la route / déclarée dans mvc/routes.py. Modifiez-les pour construire votre application.

Pour aller plus loin

Construire un starter pédagogique

Listez les starters disponibles puis construisez-en un dans ce projet. 

forge starter:list
forge starter:build welcome

Générer une entité

Créez le model, le validator, le controller, les vues et les routes d'une entité. 

forge make:entity NomEntite

Préparer la base de données

Configurez MariaDB dans env/dev puis initialisez la base. 

forge db:init
